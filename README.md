# English Literature Master

**Class XI • Complete Literature Learning & Question Paper Generator**

A production-ready Progressive Web App that unifies five Class XI English literature lessons into one polished learning platform.

## Lessons Included

| Lesson | Author | Genre |
|--------|--------|-------|
| The Garden Party | Katherine Mansfield | Short Story • Modernism |
| Alias Jimmy Valentine | O. Henry | Short Story • Crime & Redemption |
| Nobel Lecture | Mother Teresa | Speech / Prose |
| Still I Rise | Maya Angelou | Poem • Protest Poetry |
| My Last Duchess | Robert Browning | Dramatic Monologue |

## Features

- **3D / glassmorphism landing page** with floating lesson cards
- **Complete lesson modules**: Author, Introduction, Summary, Study Material, Vocabulary (EN + বাংলা), Characters, Themes, Key Points, MCQ, SAQ, Broad questions, Interactive Quiz
- **Bilingual support** (English | বাংলা) for explanations and vocabulary
- **Question Paper Generator**: multi-lesson, multi-type, marks & difficulty controls, randomization, balanced distribution
- **Answer Key** matched to generated paper
- **Student Exam Mode** with timer, auto-scoring for objective questions, results
- **Progress tracking** via localStorage
- **Global search** across lessons, vocab, themes, characters
- **Installable PWA** with offline shell (service worker)
- **Print-ready** A4 question papers
- **Mobile-first** responsive design (360px–desktop)

## Deploy to GitHub Pages

1. Settings → Pages → Source: Deploy from branch `main` / (root)
2. Live URL: https://pbwsantu-collab.github.io/english-literature-master/

Vanilla HTML/CSS/JS, localStorage, Service Worker, Web App Manifest. No build step.

Educational use for Class XI (WBCHSE) curriculum.
